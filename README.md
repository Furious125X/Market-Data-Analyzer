# Market Analyzer

A lightweight Python project that loads historical crypto price data from CSV,
calculates daily returns, and produces basic performance statistics.

## Features
- CSV price data ingestion
- Daily return calculation
- Average return and volatility
- Best and worst trading days
- Moving Averages
- Win/loss day statistics

## Project Structure
- 'main.py' - function calling and output
- `analysis.py` — core analysis logic
- `prices.csv` — historical price data
- `requirements.txt` — environment requirements

## Visualisations
- Line chart of price over time
- Histogram of daily returns

## Outputs
- `price.png` — price over time
- `returns_histogram.png` — daily return distribution


## How to Run

```bash
python main.py
